# טווח — יומן מצב רוח ושינה

**טווח** הוא יומן מצב רוח מינימליסטי בעברית, המאפשר לתעד בנפרד את שיא מצב הרוח ואת שפל מצב הרוח בכל יום, לצד שעות שינה והערה אופציונלית.

האפליקציה היא אתר סטטי (HTML, CSS ו־JavaScript) עם תמיכה בהתקנה כ־PWA. אין צורך בשרת, חשבון או שירות חיצוני.

## תכונות

- בחירה נפרדת של שיא מצב הרוח בסולם `0` עד `+4`, ושפל מצב הרוח בסולם `0` עד `−4`.
- רישום שעות שינה בקפיצות של חצי שעה (0–24).
- הערה יומית אופציונלית.
- גרפים של מצב הרוח ושל שעות השינה ב־14 הימים האחרונים.
- צפייה ועריכה של רישומים קודמים.
- ייצוא וייבוא גיבוי כ־JSON, וייצוא CSV.
- ממשק RTL נגיש יחסית, מותאם למסכי טלפון ומחשבים.
- PWA עם מטמון לשימוש חוזר גם ללא חיבור אינטרנט לאחר טעינה ראשונה.

## הפעלה

אפשר לפתוח את `index.html` בדפדפן, אך להתקנה כ־PWA ולשימוש ב־Service Worker יש להפעיל את האתר דרך `localhost` או HTTPS.

לדוגמה, אם Python מותקן:

```bash
python3 -m http.server 8000
```

ואז לפתוח בדפדפן: `http://localhost:8000`

אין תלויות ואין שלב build.

## פרסום ב־GitHub Pages

1. העלו את קובצי הפרויקט לשורש ענף `main` במאגר GitHub.
2. פתחו **Settings → Pages**.
3. תחת **Build and deployment**, בחרו **Deploy from a branch**.
4. בחרו בענף `main`, בתיקייה `/(root)`, ושמרו.
5. GitHub יציג את כתובת האתר כאשר הפרסום יושלם.

> ב־GitHub Free, פרסום ב־GitHub Pages זמין עבור מאגרים **ציבוריים**. אין להעלות למאגר נתונים אישיים, גיבויים, קובצי JSON/CSV של המעקב או מידע רפואי.

## פרטיות ושמירת נתונים

- כל הרשומות נשמרות באמצעות `localStorage` **בדפדפן ובמכשיר שבו הוזנו**.
- אין בפרויקט מנגנון חשבונות או סנכרון בין מכשירים.
- `localStorage` אינו אחסון מוצפן ואינו תחליף לגיבוי. מחיקת נתוני האתר או שימוש במכשיר משותף עלולים לחשוף או למחוק מידע.
- מומלץ לייצא גיבוי תקופתי ולשמור אותו במקום פרטי.
- גם כאשר האתר מפורסם כאתר ציבורי, הרשומות אינן נכללות בקובצי הקוד של הפרויקט ואינן נשלחות לשרת על־ידי האפליקציה.

```text
icon-512.png        אייקון אפליקציה
.nojekyll            פרסום סטטי ב־GitHub Pages
```
